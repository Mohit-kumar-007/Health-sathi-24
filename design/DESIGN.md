# HealthSathi24 — landing page design

Tagline: **Small steps today. Healthier tomorrows.**
Scope: public landing page only. Login is a link to `/login` (page not built yet). No register, no Google sign-in, no appointments, no clinic services, no invented ratings or user counts.

## Colour (logo-led, ivory/sage surfaces from the palette file)

| Token | Hex | Use |
|---|---|---|
| navy | `#16284B` | Headings, wordmark, footer |
| primary | `#1F7A4D` | Buttons (white text passes AA) |
| green | `#52A447` | Logo "24", accents, icons (graphics only, not text on ivory) |
| teal | `#12918F` | Secondary accent, links |
| mint | `#D4EFE2` | Icon tiles, highlights |
| ivory | `#F5F5F2` | Page background |

| white | `#FFFFFF` | Cards |

## Type and shape
Plus Jakarta Sans throughout (700 headings, 400/500 body). 16px rounded cards, soft borders, almost no shadow. Max width 1152px.

## Sections (PRD 6.2)
1. **Header** — logo, nav (Home, Topics, How it works, Contact), `Login` button. Mobile: menu toggle.
2. **Hero** — tagline headline, one-line value proposition, `Login` + `Explore topics`, and a sample lesson-screen preview (sidebar, video, notes) that mirrors the real lesson layout.
3. **Highlights** — short video lessons, notes with every video, progress that stays saved.
4. **Topics** — the four categories with original illustrations and example courses (starter list, editable by admin later).
5. **Learning journey** — Choose a topic → Watch and read → Come back and learn more.
6. **CTA band** — invite, no clinical promises.
7. **Disclaimer + footer** — educational-only notice, Contact (placeholder), Privacy, Terms.

## Rules carried from the PRD
Original copy and artwork; no CareTips or Carely branding. Semantic HTML, visible focus, alt text, reduced motion respected. Placeholder contact details until confirmed.
